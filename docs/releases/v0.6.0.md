# AIGTD Reminders v0.6.0

## 版本信息

- 版本：`0.6.0 (20)`
- 状态：Released（TestFlight 内部测试）
- 主题：自然确认、失败恢复与安全撤销

## 本次更新

- 可以直接说“执行吧”“就按这个来”确认当前方案，也可以说“算了”“取消这个方案”。
- 待确认卡片增加“执行这个计划”“调整”“取消”，按钮与文字走同一条本地执行链路。
- 待确认方案带版本和有效期；新方案会让旧方案失效，App 重启后仍能恢复当前有效方案。
- 统一本地执行策略，批量、高风险、目标不唯一和缺少前置快照的操作不会被模型绕过确认。
- 部分失败后可只重试失败项，已成功和无需修改的操作不会重复执行。
- 支持撤销创建、改标题、改时间、改备注、移动、完成状态和批量排期。
- 撤销按逆序执行，默认 10 分钟内可用；任务被外部修改时拒绝覆盖并显示冲突。
- 删除任务继续要求确认且不提供虚假恢复能力。
- 普通聊天和只读查询不显示执行卡片。
- 同一运行中即使模型更换调用标识重复发出相同写入，本地也只执行一次，避免重复创建或修改。
- 撤销完成、部分恢复、冲突和失败均显示对应终态文案，不再残留“正在处理”。
