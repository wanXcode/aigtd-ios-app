# AIGTD Reminders v0.5.0

## 版本信息

- 版本：`0.5.0 (19)`
- 状态：Post-TestFlight Hotfix / Pending Upgrade Acceptance
- 主题：结构化工具调用与多动作执行

## 本次更新

- Chat 使用结构化 Agent 编排模型决策和真实 Reminders 工具结果，不再从自然语言回复中猜测动作。
- 支持查询后修改、多个连续动作、创建清单、批量排期和逐项部分失败。
- 新增稳定 ID、写入前置条件、同名澄清、依赖跳过和确认前禁止写入。
- 新增持久化幂等账本，重复 `run_id + call_id` 不会重复创建或重复修改。
- 新增 8/12/30 秒工具超时、4 轮模型和 8 次工具调用预算以及取消保护。
- 多动作卡片在原位置从待确认更新为逐项成功、跳过、超时或失败，不再只展示笼统结果。
- 待确认卡片在 App 重启后可以安全恢复执行。
- 新增隐私脱敏运行日志，不保存完整标题、备注、上下文或 API Key。
- 完整系统清单目录会进入 Agent 上下文，空清单不再因没有任务而丢失。
- 显式指定的清单不存在时，计划会先创建清单，再按依赖顺序创建或移动任务。
- 补充新建任务的标题和时间时，只保留一次创建结果，不再追加等价修改和“无需修改”。
