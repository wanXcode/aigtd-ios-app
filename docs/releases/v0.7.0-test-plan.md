## 3. Chat 丝滑交互

1. 单次点击输入框即可聚焦。
2. 键盘弹出后最后一条消息保持可见。
3. 用户上滑阅读历史后，流式回复不拉回底部。
4. 键盘交互收起不强制回到底部。
5. “回到最新”恢复自动跟随。
6. 输入框 1～5 行平滑增长。
7. 超过 5 行后只在输入框内部滚动。
8. 300 条历史消息下输入、滚动和流式回复无阻塞性卡顿。

## 4. 回复与卡片

9. 普通聊天不显示或闪现执行卡片。
10. 查询只显示自然结论和只读任务列表。
11. 单动作只表达一次结果。
12. 多动作只对应一张待确认卡。
13. 卡片从待确认到结果保持同一位置和身份。
14. 卡片增长不改变用户正在阅读的历史位置。
15. 工具失败不显示成功文案。
16. 调整、取消、执行和撤销作用于当前有效方案。

## 5. 语音输入

17. 未聚焦的空输入框显示“发消息或按住说话…”，聚焦后显示“请输入...”。
18. 点击左侧语音图标后，输入区切换为左侧键盘图标和右侧“按住 说话”。
19. 点击键盘图标返回文字输入，并直接恢复键盘和输入焦点。
20. 普通轻点输入框或“按住 说话”不会误弹语音卡片，只有长按才进入录音层。
21. 录音中显示实时文字、波形和时长，多句话连续识别时前文不会消失。
22. 松手后全部识别文字进入可编辑输入框、键盘保持显示，并且不会自动发送。
23. 已有草稿时语音追加不覆盖原文；清空文字后键盘仍保持显示。
24. 上滑取消恢复原草稿，识别失败和系统中断保留可靠文字。
25. VoiceOver 可完成模式切换、开始、结束、编辑和发送。

## 6. 任务、设置与引导

26. 任务页没有复选框、加号、滑动编辑和行内编辑暗示。
27. 任务只读详情可选择“让小满调整”。
28. 空清单仍然显示。
29. 清单和任务不被自定义规则擅自重排。
30. 同步只显示“刚刚同步”或过去时间，不出现“秒后”。
31. Release 构建看不到模型、接口、API Key、Prompt 和诊断。
32. 首次进入 Chat 只出现一次小满欢迎语。
33. 麦克风权限只在第一次使用语音时请求。

## 7. 兼容与安全回归

35. 同名任务先澄清，不擅自操作。
36. 外部修改冲突阻止旧方案覆盖新状态。

3. 核对聊天、AI 服务、长期记忆和系统任务均保留。
