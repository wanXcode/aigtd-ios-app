## 3. Chat 丝滑交互

1. 单次点击输入框即可聚焦。
2. 键盘弹出后最后一条消息保持可见。
3. 用户上滑阅读历史后，流式回复不拉回底部。
4. 键盘交互收起不强制回到底部。
5. “回到最新”恢复自动跟随。
6. 输入框 1～5 行平滑增长。
7. 超过 5 行后只在输入框内部滚动。
8. 300 条历史消息下输入、滚动和流式回复无阻塞性卡顿。

## 4. 回复与卡片

9. 普通聊天不显示或闪现执行卡片。
10. 查询只显示自然结论和只读任务列表。
11. 单动作只表达一次结果。
12. 多动作只对应一张待确认卡。
13. 卡片从待确认到结果保持同一位置和身份。
14. 卡片增长不改变用户正在阅读的历史位置。
15. 工具失败不显示成功文案。
16. 调整、取消、执行和撤销作用于当前有效方案。

## 5. 语音输入

17. 空输入框显示“发消息或按住说话…”。
18. 轻点打开键盘，长按进入录音层。
19. 录音中显示实时文字、波形和时长。
20. 上滑取消恢复原草稿。
21. 松手后文字进入输入框但不发送。
22. 已有草稿时语音追加不覆盖原文。
23. 识别失败和系统中断保留可靠文字。
24. VoiceOver 可完成开始、结束、编辑和发送。

## 6. 任务、设置与引导

25. 任务页没有复选框、加号、滑动编辑和行内编辑暗示。
26. 任务只读详情可选择“让小满调整”。
27. 空清单仍然显示。
28. 清单和任务不被自定义规则擅自重排。
29. 同步只显示“刚刚同步”或过去时间，不出现“秒后”。
30. Release 构建看不到模型、接口、API Key、Prompt 和诊断。
31. 首次进入 Chat 只出现一次小满欢迎语。
32. 麦克风权限只在第一次使用语音时请求。

## 7. 兼容与安全回归

33. `0.6.0` 的创建、查询、修改、移动、完成、删除、排期、确认、调整、取消、部分失败和撤销全部通过。
34. 同名任务先澄清，不擅自操作。
35. 外部修改冲突阻止旧方案覆盖新状态。
36. 清除上下文和长期记忆不删除聊天历史或 Reminders 任务。

## 8. TestFlight 覆盖升级

1. 在 `0.6.0 (20)` 中保留聊天、模型配置、长期记忆和系统 Reminders 任务。
2. 不卸载 App，直接从 TestFlight 升级到 `0.7.0 (21)`。
3. 核对聊天、AI 服务、长期记忆和系统任务均保留。
4. 快速回归创建、两动作待确认、方案调整、同名澄清、撤销和普通聊天。
5. 核对小满、两个 Tab、新输入框和只读任务概览已经生效。

注意：本候选版本不应先卸载再安装。`0.7.0` 已从安装包移除客户端密钥，覆盖升级会保留 `0.6.0` 已写入本机的模型和语音配置；全新安装需等待服务端 AIGTD 代理上线后再验收。
