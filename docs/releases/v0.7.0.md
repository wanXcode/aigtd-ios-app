# AIGTD Reminders v0.7.0

## 版本信息

- 版本：`0.7.0 (22)`
- 状态：TestFlight 内部候选
- 主题：公开产品体验升级
- 升级基线：`0.6.0 (20)`

## 已完成更新

- 默认事务助理统一为“小满”，首次进入 Chat 提供一次简短欢迎。
- 公开导航收敛为 `AIGTD` 与 `任务` 两个 Tab。
- 重构 Chat 输入框、键盘联动、历史阅读、流式回复和卡片状态过渡。
- 输入框使用“发消息或按住说话…”入口，支持长按录音、上滑取消和松手转可编辑草稿。
- 普通聊天不显示执行卡片；任务卡片在同一位置从待确认更新到真实结果。
- 任务页改为区别于 Apple Reminders 的只读 AIGTD 任务概览。
- 清单顺序尽量跟随系统并显示空清单；不再擅自按任务状态、时间和标题重排。
- Release 产品隐藏模型、接口、密钥、Prompt 和诊断等开发者配置。
- 统一暖白、品牌蓝和小满杏橙视觉，补齐 Dynamic Type、VoiceOver 与 Reduce Motion。
- 修复 Build 21 因 CocoaPods 动态框架未嵌入安装包而导致的启动即崩溃。
- `xcodegen generate` 后自动执行 `pod install`，并新增归档动态依赖门禁，避免同类发布事故复发。

## Build 21 启动崩溃结论

- 表现：从 TestFlight 安装后，点击 AIGTD 立即被系统终止，尚未进入 SwiftUI 启动逻辑。
- 根因：主程序链接了 `@rpath/TTNetworkManager.framework/TTNetworkManager`，但 Build 21 的 App 包没有 `Frameworks` 目录；`xcodegen` 重建工程后遗漏了 CocoaPods 的 `[CP] Embed Pods Frameworks` 阶段。
- 证据：Build 21 归档的依赖门禁稳定报出 `missing embedded dependency`；Build 22 的 Release App 与正式 Archive 均通过同一门禁，且框架为 arm64。
- 处理：Build 21 不作为可验收候选；仅验收 Build 22 及之后构建。

## 安全与升级说明

- `0.7.0` 安装包不再包含 `Secrets.local.plist`、示例密钥文件或面向开发者的模型配置入口。
- 本轮 TestFlight 应在 `0.6.0 (20)` 上直接覆盖安装，以保留设备上已有的本地模型和语音配置；不要先卸载旧版。
- 全新安装在服务端 AIGTD 模型与语音代理上线前不会自动获得 AI 凭证，因此暂不作为公开 App Store 的新用户交付方式。
- `0.6.0` 曾使用过的客户端凭证须在正式公开发布前轮换，公开版只允许通过服务端代理访问模型与语音服务。
- EventKit 不提供可靠的手工排序接口；任务页优先采用系统返回顺序，并以会话内稳定顺序作为可解释降级，不自行按标题、时间或完成状态重排。
