# AIGTD Reminders v0.5.0 测试计划

## 1. 测试版本

- 版本：`0.5.0 (19)`
- 基线：TestFlight `0.4.0 (17)`
- 主题：结构化工具调用、多动作执行与真实结果闭环

## 2. 测试前准备

1. 从 Xcode 选择 `AIGTDReminders` scheme 和测试 iPhone。
2. 确认 Signing Team 为 `SMARTEFFI PTE. LTD.`。
3. 编译安装后，在 Agent 页确认模型配置可用。
4. 给 AIGTD 完整 Reminders 访问权限。
5. 新建一个“0.5 验收”清单，测试任务统一使用“验收”前缀。

## 3. 核心验收

### 用例 1：查询后改单任务

准备：创建“验收会议”，安排到下周一上午 10 点。

发送：`把下周一的验收会议改到下午 3 点`

通过标准：App 先按真实 Reminders 查询并唯一定位；最终时间为下午 3 点；没有新建同名任务；卡片显示修改成功。

### 用例 2：同名任务必须澄清

准备：创建两条“验收同名会议”，时间分别为明天 14:00 和后天 15:00。

发送：`删除验收同名会议`

通过标准：App 列出多个候选并要求说得更具体；确认前两条均未删除；不得默认选择第一条。

### 用例 3：修改加创建

发送：`把验收会议改到下午 3 点，再提醒我 2 点半带资料`

通过标准：出现一张多动作卡片和“执行这个计划”按钮；点击前 Reminders 无变化；点击后原会议改期且新增“带资料”；卡片逐项显示真实状态。

### 用例 4：创建清单后移动

准备：创建两条“验收移动 A/B”，并在 Chat 中查看它们。

发送：`新建验收发布清单，把刚才两条移进去`

通过标准：确认后只创建一个“验收发布”清单；两条任务移动成功；若清单已存在则复用且不重复创建；创建失败时移动步骤显示已跳过。

### 用例 5：只读查询

发送：`项目清单里哪些任务没有时间？`

通过标准：回复来自真实 Reminders；不显示执行卡片；不修改任何任务。

### 用例 6：批量排期和确认

准备：创建三条无时间的“验收排期 A/B/C”，在 Chat 中查看它们。

发送：`把刚才三条安排到本周三到周五`

通过标准：先生成方案，确认前时间不变；点击后逐项写入；同一方案重复点击不产生第二次写入。

### 用例 7：外部修改冲突

准备：生成用例 6 的方案但不要确认，然后在系统 Reminders 手动修改其中一条时间。

操作：返回 AIGTD 点击“执行这个计划”。

通过标准：外部修改项返回冲突且不被覆盖；其他独立项继续；整体卡片为部分完成。

### 用例 8：部分失败

准备：生成三项计划但不要确认，然后在系统 Reminders 删除其中一条。

操作：返回 AIGTD 确认执行。

通过标准：另外两项继续执行；删除项显示失败或未找到；最终回复不得声称全部成功。

### 用例 9：普通聊天

发送：`我今天有点累，不想整理任务。`

通过标准：自然回复；无工具卡片闪现；Reminders 无变化。

### 用例 10：待确认卡片恢复

准备：生成一个多动作待确认卡片，不点击按钮；彻底结束 App 后重新打开。

操作：点击原卡片的“执行这个计划”。

通过标准：能够恢复并执行；若任务已变化则安全报告冲突；不得重复创建或重复修改。

### 用例 11：隐私

关闭“允许读取任务备注”和“允许包含已完成任务”，再查询带私人备注的任务。

通过标准：回复、工具结果和诊断详情均不出现备注；已完成任务不进入查询结果。

### 用例 12：升级数据安全

从 TestFlight 旧构建直接升级到 `0.5.0 (19)`。

通过标准：原聊天、设置、长期记忆和系统 Reminders 任务完整；历史卡片仍可阅读。
